# Agent × Real2Sim2Real

Recent papers on agents and real-to-sim-to-real, collected by a daily routine.

- **Agent × Real2Sim2Real**: an agent (LLM / VLM / agentic pipeline) builds, edits, checks or uses the simulation made from the real world.
- **Real2Sim2Real**: real-to-sim, sim-to-real loops, digital twins, scene reconstruction for policy training or evaluation, without an agent.

Newest first. Each line: date, paper, one-line why it matters.

## Agent × Real2Sim2Real

- 2026-10-20 [NeoWorld-3: From Pixels to Code-Defined Physical Worlds](https://arxiv.org/abs/2610.27690) — Coding-agent framework that rebuilds interactive objects and scenes from images as executable programs, with tool APIs for inspect-edit-refine and physics validation; trajectories planned in the twins run zero-shot on a real dual-arm robot.
- 2026-10-16 [Self-Building Labs](https://arxiv.org/abs/2610.23826) — Given a scientific goal, an agent system builds the lab layout, its digital twin, robot skills and workflows from whatever setup exists, then runs a real quantum-dot synthesis experiment.
- 2026-10-15 [GRASE: Geometry-native Real-to-sim Agentic Scene Modeling from Video](https://arxiv.org/abs/2610.21498) — Agent places generated assets and keeps revising them against the captured multi-view video, turning a video into a simulation-ready scene instead of a one-pass pipeline.
- 2026-10-13 [RoboSimStudio: An Interactive Toolkit for Human and Agent Rapid Real2Sim of Robot Manipulation Tasks](https://arxiv.org/abs/2610.18835) — Newton-based toolkit that exposes solver, contact model and physics parameters so humans or coding agents can tune a sim to observed real behavior.
- 2026-10-12 [PhysCodeGym: Benchmarking Coding Agents for Physically Verifiable 4D Reconstruction](https://arxiv.org/abs/2610.17288) — Benchmark of 156 video-to-simulation tasks where coding agents write and revise Blender scenes from simulation feedback; counterfactual tests expose contact and support errors that ordinary checks miss.
- 2026-10-12 [D-World: An Explicit World-Language-Action Model with Recursive Self-Improvement under Dual Control](https://arxiv.org/abs/2610.17114) — LLM agents write the scene as an executable digital twin and revise its states and physical parameters after each real action chunk; a real-to-sim-to-real loop on a dual-arm robot.
- 2026-10-12 [Unravel: Recovering an Interactive 3D Scene from a Single Image](https://arxiv.org/abs/2610.16146) — Agentic harness peels a single image object by object with VLM planning and verified edits, rebuilds movable assets, physically settles the scene and audits placement.
- 2026-10-08 [USDCraft: Geometrically Grounded Programmatic Modeling of Articulated 3D Assets for Simulation](https://arxiv.org/abs/2610.11322) — LLM writes and revises programs for articulated USD assets from partial real geometry, loadable into Isaac Sim for real-to-sim-to-real manipulation.
- 2026-10-07 [Agentic RSR: Real-to-Sim-to-Real through Scene Reconstruction and Execution-Grounded Robot Policies](https://arxiv.org/abs/2610.10479) — From a workspace video, an agent rebuilds the scene in MuJoCo and a coding agent develops the policy, then carries it to the real robot through a shared task interface.
- 2026-10-02 [RoboBridge: A Self-Evolving Embodied Agent Framework for Sim-to-Real Transfer](https://arxiv.org/abs/2610.02717) — Tool-using agent treats sim-to-real as continued adaptation of executable task skills, carrying procedural knowledge from simulation into the real world and adapting after deployment.
- 2026-10-01 [LiteReality-Agent: An Agentic System for Interactable 3D Indoor Scene Reconstruction](https://arxiv.org/abs/2610.01863) — Treats room reconstruction as coding: an agent edits an executable Room.py with an observe-edit-verify harness to produce articulated, sim-ready digital twins from RGB-D scans.
- 2026-10-01 [Recova: Agent-Guided Failure Recovery for Autonomous Robotic Manipulation](https://arxiv.org/abs/2610.01178) — Agent diagnoses failures and tests recovery programs in a reconstructed digital twin, then verifies and refines them with real-robot experience.
- 2026-09-30 [EmbodiRSI: Recursive Self-Improvement for Data-Efficient Robot Adaptation](https://arxiv.org/abs/2609.38905) — Agentic recursive self-improvement in task-specific sims built from deployment scenes; uses policy failures to steer data generation before transfer back to the real robot.
- 2026-09-29 [Real2Gym: Building Gyms from Videos, Bringing Skills to Robots](https://arxiv.org/abs/2609.37089) — Turns human/robot videos into interactive sim gyms; an agent writes manipulation code there, distills skills, and reuses them on a real Franka.
- 2026-09-28 [F4R: Failure-Driven Recognition, Reconstruction, Refinement, and Redeployment for Continual Robot Self-Improvement](https://arxiv.org/abs/2609.35575) — Agent finds real-world failures, rebuilds each as a sim environment, and refines the VLA with sim-real co-training and RL before redeploying.
- 2026-09-28 [DexAgent: An Agentic Human2Sim2Robot Framework for Dexterous Manipulation with Self-Evolving Tool Library](https://arxiv.org/abs/2609.35318) — Agent converts one egocentric human video into a verified sim reconstruction and dexterous robot trajectories, growing a reusable tool library.
- 2026-09-28 [CoDimRecon: Agentic Reconstruction of Sim-Ready 3D Scenes with Deformable Curves, Surfaces, and Volumes](https://arxiv.org/abs/2609.36024) — Agent sessions rebuild editable sim-ready scenes from multi-view RGB, including articulated objects and deformables as curves, shells or volumes.
- 2026-09-27 [Robot-GST: geometry-aware spatial-temporal robot policy representation and evaluation](https://arxiv.org/abs/2609.33872) — Builds a 3DGS + SAM3D environment from RGB-D so VLM-planned actions can be simulated and checked before real execution.
- 2026-09-27 [VPTwin: Real-Sim-Real Video Prediction for Robotic Manipulation Planning](https://arxiv.org/abs/2609.33104) — VLM rebuilds an executable twin from a real demo; Isaac Sim rollouts anchor video prediction used to verify VLM-proposed actions.
- 2026-09-21 [ARSTAG: An Agentic Real2Sim2Real System for Task-Specific Robot Data Generation](https://arxiv.org/abs/2609.24563) — Language-agent hierarchy turns one RGB image plus an instruction into a sim scene, feasible demos and randomized data for real-robot policies.
- 2026-09-21 [Fysiverse-3D-SimReady Technical Report: Agentic Physical Simulation for Pragmatic 3D World Reconstruction](https://arxiv.org/abs/2609.31715) — Single real image to a simulation-ready multi-object scene: places generated meshes, refines poses by differentiable rendering, and fixes support and stability under physics.
- 2026-09-19 [DiagGen: Agentic Generation of Deformable Assets with Sim-based Diagnostics for Robotic Simulation](https://arxiv.org/abs/2609.23103) — One in-the-wild image to a sim-ready deformable asset; a VLM agent probes regions in the simulator and routes repair cues back to the generation stage.
- 2026-09-03 [R2S-Eval: Robot Evaluation with Real-to-Sim Calibration via Vision-Language Models](https://arxiv.org/abs/2609.03276) — Runs policies in a sim calibrated to the real eval setup and uses a VLM to judge rollout quality pairwise, reducing hardware trials.
- 2026-08-31 [Lucida: Parse, Generate, and Place for Composable Real-to-Sim Scene Modeling](https://arxiv.org/abs/2608.30821) — Video-to-scene pipeline where a VLM policy places generated assets through multi-turn GUI gizmo interaction to match the real capture.
- 2026-08-29 [DREAM: Deployment-Time Demonstration Generation via Real-to-Sim for Scalable Policy Adaptation](https://arxiv.org/abs/2608.29078) — Reconstructs the deployment workspace; an LLM turns the instruction into goals and success checks, and TAMP generates verified VLA fine-tuning data.
- 2026-08-25 [NeoWorld-Pro: Programming Interactive Scenes from Monocular Images for Embodied Simulation](https://arxiv.org/abs/2608.24212) — MLLM turns one RGB image into executable scene programs (geometry, articulation, physics), refined by checking execution in a physics engine.
- 2026-08-20 [Video2DoorTraversal: Push Door Traversal via Simulated Door Twins](https://arxiv.org/abs/2608.20251) — One video of a real door becomes an articulated sim twin; a simulation-in-the-loop agent refines skill programs into demos for a wheel-legged robot.
- 2026-07-21 [Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents](https://arxiv.org/abs/2607.19190) — VLM agents convert real robot-object recordings into simulatable episodic twins, used for policy fine-tuning and as a surrogate for real evaluation.

- 2026-10-13 [Contact-UAN: Unsupervised Actuator Networks as a Residual World Model for Humanoid Control](https://arxiv.org/abs/2610.18991) — Residual actuator model fitted to recorded hardware rollouts so humanoid sim matches real contact forces; policies trained with it transfer to the real robot.
- 2026-10-12 [FEM-Validated Real-Time Modelling of Soft Tactile Deformation](https://arxiv.org/abs/2610.16667) — Tunes an FEM model of a soft tactile sensor on a few real contacts, trains a GNN surrogate on FEM data, and keeps sub-millimetre accuracy on real measurements.

- 2026-10-09 [Splat2Act: From Captured Scenes to Personalized VLA Manipulation](https://arxiv.org/abs/2610.13945) — Phone scan → building-scale 3DGS twin → auto-generated pickup demos to personalize a pretrained VLA to a user's space.
